# Mano-Basic-Computer-
Building Mano’s Basic Computer from scratch in Verilog! As part of my deep dive into computer architecture and digital integrated circuit design, I implemented the complete RTL architecture of Morris Mano’s Basic Computer Moving from architectural theory to RTL implementation and verifying the synthesis and schematic views through Xilinx Vivado

What the project covers:

Datapath & Register File: Designed and integrated 16-bit and 12-bit registers (PC, AR, DR, AC, IR, TR, etc.).

Arithmetic Logic Unit (ALU): Developed arithmetic and logic operation units supporting standard Mano instructions.

Control Unit: Structured the hardwired control logic and Sequence Counter (SC) to handle fetch, decode, and execute cycles across all 25 instructions.

Memory Subunit: Integrated RAM modules and data routing using a shared internal Common Bus architecture.
